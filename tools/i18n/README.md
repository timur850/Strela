# Английский язык (i18n)

Мини-аппка переводится на лету скриптом `site/i18n.js`: он подменяет русские тексты на экране по словарю.
Язык выбирается сам по языку Telegram (русскоязычные → RU, остальные → EN), игрок может переключить в профиле или в меню ☰.

Добавил новые тексты в код:
1. `python3 tools/i18n/check.py` — покажет строки без перевода.
2. Допиши их в `tools/i18n/tr3.py` (`"Русский": "English"`, подстановки `{0}`, `{1}` как в оригинале).
3. `python3 tools/i18n/build.py site/i18n.js` — пересоберёт словарь.
Перед коммитом: python3 tools/bump.py (метки версий у скриптов)
